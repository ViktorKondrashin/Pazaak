# Pure Pazaak 

http://13.140.86.217/

**Pure Pazaak** — веб-реализация карточной игры Пазаак из вселенной *Star Wars: Knights of the Old Republic*. Проект поддерживает одиночную игру против бота и сетевые матчи между игроками.

Приложение разработано на Angular и Node.js с использованием SQLite для хранения данных. Доступен запуск из исходного кода и развёртывание через Docker.

**Текущая версия:** `5.1.0`

## Возможности

- Одиночная игра против компьютерного соперника.
- Сетевая игра между двумя пользователями.
- Создание игровых комнат и подключение к матчам.
- Управление игровыми картами и дополнительной колодой.
- Автоматическая обработка игровых ходов и определение результатов.
- Адаптивный веб-интерфейс.
- Развёртывание на локальном компьютере или удалённом сервере.

## Установка и запуск

### 1. Запуск из исходного кода

Для запуска необходимы [Node.js 24](https://nodejs.org/) и npm.

Клонируйте репозиторий:

```bash
git clone <URL-репозитория>
cd pure-pazaak
```

Установите зависимости:

```bash
npm ci
```

Запустите приложение:

```bash
npm start
```

После запуска приложение доступно по адресу:

http://localhost:3000

### 2. Запуск через Docker

Готовый образ опубликован в [Docker Hub](https://hub.docker.com/r/molodchikiznkvd/pure-pazaak).

**Требования:**

- [Docker Desktop](https://docs.docker.com/desktop/) — для Windows и macOS.
- [Docker Engine](https://docs.docker.com/engine/install/) — для Linux.

На Windows необходимо использовать режим Linux-контейнеров.

Скачайте готовый образ:

```bash
docker pull molodchikiznkvd/pure-pazaak:5.1.0
```

Создайте и запустите контейнер:

```bash
docker run -d \
  --name pure-pazaak \
  --restart unless-stopped \
  -p 80:3000 \
  -v pazaak_data:/app/data \
  molodchikiznkvd/pure-pazaak:5.1.0
```

Приложение будет доступно по адресу:

http://localhost

На Linux при необходимости выполняйте команды Docker с `sudo`.

### 3. Запуск через Docker Compose

**Требования:** Docker Engine и Docker Compose V2 (входит в Docker Desktop, для Linux устанавливается как [Compose plugin](https://docs.docker.com/compose/install/linux/)).

В корневом каталоге проекта используется файл `compose.yaml` со следующей конфигурацией:

```yaml
services:
  pazaak:
    image: molodchikiznkvd/pure-pazaak:5.1.0
    container_name: pure-pazaak
    restart: unless-stopped
    ports:
      - "80:3000"
    volumes:
      - pazaak_data:/app/data

volumes:
  pazaak_data:
    name: pazaak_data
```

Из каталога с `compose.yaml` выполните:

```bash
docker compose up -d
```

При отсутствии локального образа Docker автоматически загрузит его из Docker Hub.

Приложение будет доступно по адресу:

http://localhost

При развёртывании на VPS используйте публичный IP-адрес или доменное имя сервера. TCP-порт 80 должен быть свободен и доступен для входящих подключений.

## Сборка Docker-образа из исходного кода

Для самостоятельной сборки перейдите в корневой каталог проекта с `Dockerfile` и выполните:

```bash
docker build -t pure-pazaak:5.1.0 .
```

Запуск собранного образа:

```bash
docker run -d \
  --name pure-pazaak \
  -p 80:3000 \
  -v pazaak_data:/app/data \
  pure-pazaak:5.1.0
```

Перед запуском необходимо убедиться, что контейнер с таким именем ещё не существует.

## Управление контейнером

| Действие | Docker | Docker Compose |
|---|---|---|
| Просмотр состояния | `docker ps` | `docker compose ps` |
| Просмотр логов | `docker logs pure-pazaak` | `docker compose logs -f` |
| Остановка | `docker stop pure-pazaak` | `docker compose stop` |
| Повторный запуск | `docker start pure-pazaak` | `docker compose start` |
| Удаление контейнера | `docker rm pure-pazaak` | `docker compose down` |

Команды Docker Compose выполняются из каталога с `compose.yaml`.

## Архитектура

Приложение построено по клиент-серверной архитектуре.

- **Клиент (Angular):** пользовательский интерфейс, отображение игрового поля, обработка действий игрока и логика одиночной игры.
- **Сервер (Node.js):** обработка сетевых подключений, управление игровыми комнатами и проверка действий участников сетевого матча.
- **База данных (SQLite):** хранение данных приложения.

В одиночном режиме основная игровая логика выполняется в браузере. В сетевом режиме клиенты взаимодействуют с сервером, который обеспечивает согласованное состояние матча.

В production-среде Node.js также обслуживает собранную клиентскую часть приложения.

## Хранение данных

Для постоянного хранения данных SQLite при запуске через Docker предусмотрен именованный том `pazaak_data`.

Данные тома сохраняются при остановке и пересоздании контейнера. Удаление контейнера не приводит к автоматическому удалению тома.

Для удаления контейнеров вместе с томами Docker Compose используется команда:

```bash
docker compose down -v
```

**Внимание:** удаление тома приведёт к потере хранящихся в нём данных.

## Развёртывание на сервере

Приложение может размещаться на VPS с Linux и использоваться как самостоятельный HTTP-сервер либо работать за обратным прокси Nginx.

При прямом подключении Docker публикует порт приложения на сервере. Если порт 80 уже используется Nginx или другим сервисом, необходимо освободить его либо выбрать другой внешний порт.

Для публичного развёртывания с HTTPS рекомендуется использовать обратный прокси с TLS-сертификатом.
